# Layla Talking Story Mini-App

zeta風の「人物と会話しながら物語が進む」個人向けLayla Mini-Appです。主人公やキャラクターを固定せず、作品ごとに設定できます。

## 機能
- 作品タイトル、確定本文、ユーザーの台詞や行動、逐次生成、生成停止と再試行、直近のやりとり
- あらすじ、メインキャラ設定、世界観、**章に依存しない自由記憶メモ**、禁止展開、禁止ワード、ユーザー役割、作品ゴール、固定指示
- 全設定に **通常の日本語文章** と **[海:名称≡<虎田海>]** 形式を自由に混在可能（入力文をモデルに伝える方式）
- 直近確定本文の参照文字数、生成の目安文字数、展開速度、視点、サンプリング設定
- Layla SQLiteを主に保存、IndexedDBへ退避、次回起動時に新しい退避編集をSQLiteへ復元
- **JSON: 全設定＋本文＋対話履歴** の復元用バックアップ。TXT/Markdown: 本文用（読み込み時には現在の設定を保持）
- 本文の直接編集（履歴と本文にずれがある場合、本文が確定原稿となります）
- 添付の緑の時計画像を縮小してアプリアイコンに使用

## 使い方
1. Layla有料版で使うGGUFモデルを選択しておきます。Mini-App側ではGGUFの直接読込・切替はできません。
2. GitHubの Actions → Build Layla Talking Story Mini-App の成功した実行 → Artifacts からZIPを取得。ZIP直下に index.html, app.json, icon.jpg が入っています。
3. LaylaでZIPをMini-Appとしてインポートします。
4. 「設定」で作品、キャラ、世界観、自由メモを記入し「本文へ戻る」。入力欄に台詞や行動を書き、「この先を進める」を押します。
5. JSONバックアップは定期的にiOS「ファイル」へ保存し、再インポート前に開けるか確認してください。

## データ取り扱い
会話・個人設定・作品本文・GGUFファイルをGitHubへアップロードする仕組みはありません。Laylaが端末内で推論します。GitHub Actionsはビルド時のみネット接続を使用します。ブラウザ単独ではLaylaブリッジがないため、本物のLLM生成は動作しません。

## 開発
Node.js 22推奨。`npm install` → `npm test` → `npm run build && npm run verify`

**留意事項**: iPhone/iPadのLaylaで、生成停止・SQLite・ファイル共有などの実機動作はビルド成功とは別に確認が必要です。繰り返しペナルティの検索範囲と傾斜はLaylaホスト側の反映保証はありません。
